# YouranMod

悠然服务器自己的 Minecraft 1.12.2 Forge 模组（modid `youranmod`）：矿泉水、汞镓氯气、货币、主城维度与 `/youran`、`/hub` 指令、游戏内 IPv6 网络（服务器内网，接口在 `moe.qingu.youran.api.network`）等服务器专属内容。用 `./gradlew build` 构建（需要 JDK 25 运行 Gradle），出两个 jar：`youranmod-<版本>.jar` 是服务器用的完整包，`youranmod-<版本>-client.jar` 是给玩家的客户端包（不含服务端的网络实现）。
